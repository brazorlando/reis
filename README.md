# Reis Manager

Sistema de Gestão Escolar da **Escola Rei dos Reis** (Manga, Beira — Moçambique).

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (Auth + PostgreSQL + Storage)
- Vercel (deploy)

## Deploy

Este projeto está conectado à Vercel. Cada push na branch `main` faz deploy automático.

## Módulos

- [ ] Autenticação (PIN + login por role)
- [ ] Painel do Diretor
- [ ] Painel do Professor
- [ ] Painel do Aluno
- [ ] Painel do Encarregado
